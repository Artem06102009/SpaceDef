# SpaceDef
SpaceDef - это классический вертикальный космический шутер (shoot 'em up). Игрок управляет космическим истребителем, который должен сражаться с волнами вражеских кораблей, собирать бонусы и побеждать боссов на различных уровнях.

ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Создать: · Меню игры с выбором опций · Игровой процесс с управлением кораблем · Экран поражения со статистикой · Экран победы при завершении всех уровней

Игровые объекты: Игрок (Player) · Спрайт: космический корабль · Механики: · Стрельба (Пробел/Z) · Получение урона · Сбор бонусов

Враги (Enemy) · Спрайты: 4 варианта спрайтов · Характеристики: · Здоровье: 30-50 HP Хаотичное движение

Босс (Boss) · Появление каждый уровень(в конце) · Характеристики: · Здоровье: 200-450 HP · Атаки: 3 типа

ПОЯСНИТЕЛЬНАЯ ЗАПИСКА Название: SpaceDef

Автор: Колегов Артём Игоревич под самый чутким руководством Бушенева Игоря Владимировича

Идея: Предложил папа по описанию из своего детства, вдохновился и решил создать ностальгическую игру в стиле 90-ых. SpaceDef - это классический вертикальный космический шутер (shoot 'em up). Игрок управляет космическим истребителем, который должен сражаться с волнами вражеских кораблей.

Реализация:

Класс Player - основной класс игрока, прописано его движения Класс Bullet - класс пулек, которыми стреляет космический корабль Класс Enemy - основной класс рандомной генерации врагов Класс EnemyBullet - класс пулек наших врагов Класс Particle - класс анимации при убийстве врага Класс StartView - старт игры, основные требования Класс GameOverView - класс конца игры, итоговый вывод результатов Класс GameView - класс игры
